# 📖 1. Description

## 🧩 Une skill Hermes, c'est quoi ?

Une **skill**, c'est un dossier déposé dans `~/.hermes/skills/` et contenant un fichier `SKILL.md` : rien d'autre que des instructions que l'agent charge quand la discussion tombe sur son sujet.

```text
~/.hermes/skills/founder-board/
└── SKILL.md      ← le mode d'emploi que Hermes lit
```

> 💡 **Pas de code, pas de plugin, pas d'API key.** Hermes lit la description de chaque skill et l'active au bon moment, tout seul.

Chaque skill écrit ses résultats dans le dossier `founder/` de ton projet. Les skills suivantes **relisent ce qui existe déjà** : le pack est cumulatif, chaque étape nourrit la suivante.

```text
mon-projet/founder/
├── idea.md          ← ton idée, formalisée
├── board.md         ← le vote du board
├── competitors.md   ← la carte concurrentielle
├── panel/results.md ← ce qu'ont dit les 100 acheteurs
└── ...              ← pricing, offre, CFO, marketing, plan
```

---

## 👥 Les 11 skills, présentées comme une équipe

| Skill | Rôle dans l'équipe | Ce qu'elle produit |
|---|---|---|
| 🏛️ `founder-board` | Le conseil d'administration | 3 administrateurs (lenses Offers / Monopoly / Product) notent, riskent, votent **FUND / FUND IF / PASS** |
| 🕵️ `founder-competitors` | L'éclaireur | Concurrents directs, indirects, substituts : prix, positionnement, plaintes clients — chaque fait sourcé |
| 🛒 `founder-consumer` | Le panel consommateurs | Jusqu'à 100 acheteurs simulés : qui achète, qui passe, et *pourquoi* |
| 🏷️ `founder-pricing` | Le stratège prix | Fourchette de prix acceptable (méthode Van Westendorp), confrontée concurrence et marge |
| 🎁 `founder-offer` | L'architecte d'offre | L'offre stack : bonuses, garantie, urgence réelle, nom |
| 💰 `founder-cfo` | Le directeur financier | Marge réelle, seuil de rentabilité, année 1 mois par mois, cash nécessaire |
| 📣 `founder-marketing` | Le directeur marketing | Positionnement, canaux où sont tes acheteurs, campagne 30 jours, hooks, coût d'acquisition max |
| 🎨 `founder-brand` | Le designer de marque | Noms candidats + vérifs à faire, ton de voix, promesse |
| 🚚 `founder-ops` | Les opérations | Fournisseurs, routines, licences, registre des risques |
| 🚀 `founder-launch` | Le grand jour | Le checklist du jour J |
| 📋 `founder-plan` | Le compilateur | Assemble tous les outputs du pack en un plan complet |

## 🔀 L'ordre du pack

```text
board → competitors → consumer → pricing → offer → cfo → marketing → brand → ops → launch → plan
```

Chaque skill te **suggère la suivante** à la fin de son run. Et chacune peut tourner seule : elle lit simplement ce qui existe déjà dans `founder/`.
