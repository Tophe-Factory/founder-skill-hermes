# 1. Description

## Une skill Hermes, c'est quoi ?

Une **skill** est un dossier déposé dans `~/.hermes/skills/`, contenant un fichier `SKILL.md` : des instructions que l'agent charge quand la conversation correspond à son sujet. Pas de code à maintenir, pas de commande à retenir : Hermes lit la description de chaque skill et l'active au bon moment.

Chaque skill du pack écrit ses résultats dans un dossier `founder/` de ton projet (idée, votes du board, réponses des acheteurs, plan financier...), et les skills suivantes relisent ce qui existe déjà. Le pack est donc **cumulatif** : plus tu avances, plus tes analyses sont nourries.

## Les 11 skills

| Skill | Rôle | Ce qu'elle produit |
|---|---|---|
| `founder-board` | Conseil d'administration | 3 administrateurs (lenses Offers / Monopoly / Product) notent l'idée et votent FUND / FUND IF / PASS |
| `founder-competitors` | Éclaireur concurrence | Carte des concurrents, prix, positionnements, plaintes clients, chaque fait sourcé |
| `founder-consumer` | Panel consommateurs | 100 acheteurs simulés (20 en mode rapide), qui achète, qui passe, pourquoi |
| `founder-pricing` | Stratège prix | Fourchette de prix acceptable (méthode Van Westendorp) confrontée à la concurrence et à la marge |
| `founder-offer` | Architecte d'offre | L'offre complète : bonuses, garantie, urgence, nom |
| `founder-cfo` | Directeur financier | Marge réelle, seuil de rentabilité, année 1 mois par mois, trésorerie nécessaire |
| `founder-marketing` | Directeur marketing | Positionnement, canaux, campagne de lancement datée sur 30 jours, hooks |
| `founder-brand` | Designer de marque | Candidats de nom avec vérifications à faire, ton, promesse |
| `founder-ops` | Responsable opérations | Fournisseurs, routines, outils, licences, registre des risques |
| `founder-launch` | Plan de lancement | Le checklist du jour J |
| `founder-plan` | Compilateur | Assemble tous les outputs du pack en un plan |

## L'ordre du pack

```
board -> competitors -> consumer -> pricing -> offer -> cfo -> marketing -> brand -> ops -> launch -> plan
```

Chaque skill peut aussi tourner seule : elle lit simplement ce qui existe déjà dans `founder/`.

## Ce qui a été adapté pour Hermes

- L'outil `delegate_task` de Hermes remplace le mode sub-agent de Claude Code (board à 3 voix, panel de 100 acheteurs)
- Les chemins de fichiers utilisent `~/.hermes/skills/`
- Les mentions `argument-hint`, `$ARGUMENTS` (propres à Claude Code) ont été retirées
- Scripts Python originaux conservés tels quels (`panel.py`, `unit_economics.py`, `van_westendorp.py`, `compile.py`)
