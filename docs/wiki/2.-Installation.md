# ⚙️ 2. Installation

> ⏱️ **Budget : 2 minutes.** Trois commandes, aucune dépendance à installer.

## 🧾 Prérequis

| Prérequis | Vérification |
|---|---|
| ✅ **Hermes Agent** installé et fonctionnel ([doc officielle](https://hermes-agent.nousresearch.com/docs)) | `hermes --version` répond |
| ✅ **Python 3.8+** (pour les scripts du pack, zéro pip install) | `python3 --version` ≥ 3.8 |

---

## Étape 1️⃣ — Télécharger le pack

```bash
git clone https://github.com/Tophe-Factory/founder-skill-hermes.git
```

## Étape 2️⃣ — Copier les skills

```bash
cp -r founder-skill-hermes/skills/founder-* ~/.hermes/skills/
```

> ⚠️ Les scripts (`panel.py`, `unit_economics.py`...) **voyagent avec leurs skills**. Copie les dossiers entiers, ne sépare rien.

**Résultat attendu** — 11 dossiers :

```text
~/.hermes/skills/
├── founder-board/
├── founder-brand/
├── founder-cfo/
├── founder-competitors/
├── founder-consumer/
├── founder-launch/
├── founder-marketing/
├── founder-offer/
├── founder-ops/
├── founder-plan/
└── founder-pricing/
```

## Étape 3️⃣ — Vérifier

Lance ou redémarre Hermes dans n'importe quel dossier, puis demande-lui simplement :

> « Peux-tu me dire quelles founder skills sont installées ? »

Hermes doit citer `founder-board`, `founder-consumer` et les autres. 🎉

---

## 🔘 Désinstallation

```bash
rm -rf ~/.hermes/skills/founder-*
```

> 💡 Les résultats de tes runs vivent dans `founder/` **dans tes projets**, pas dans les skills : tu peux retirer le pack sans rien perdre.

## 🆘 Ça ne marche pas ?

| Symptôme | Remède |
|---|---|
| Une skill n'apparaît pas | Vérifie que `SKILL.md` est bien **à la racine** de chaque dossier copié |
| « command not found: python3 » | Installe Python 3.8+ (paquet `python3` de ta distribution) |
|Les sous-agents refusent de démarrer | voir [3. Utilisation](3.-Utilisation) : session interactive requise pour board et panel |

➡️ **C'est installé ? Passe à [l'utilisation](3.-Utilisation)**, la plus drôle.
