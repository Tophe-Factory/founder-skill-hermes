# 2. Installation

## Prérequis

- **Hermes Agent** installé et fonctionnel ([documentation](https://hermes-agent.nousresearch.com/docs)) — ce pack ne s'occupe pas de cette partie
- **Python 3.8 ou plus récent** (pour les scripts du pack, aucune librairie à installer via pip)

Vérifie Python :

```bash
python3 --version
```

## Étape 1 : télécharger le pack

```bash
git clone https://github.com/Tophe-Factory/founder-skill-hermes.git
```

## Étape 2 : copier les skills

```bash
cp -r founder-skill-hermes/skills/founder-* ~/.hermes/skills/
```

Résultat attendu : 11 dossiers `founder-*` dans `~/.hermes/skills/`. Les scripts (`panel.py`, `unit_economics.py`...) voyagent avec leurs skills, ne les sépare pas.

## Étape 3 : vérifier

Lance ou redémarre Hermes dans n'importe quel dossier de travail, puis demande simplement :

> Peux-tu me dire quelles founder skills sont installées ?

Hermes doit citer `founder-board`, `founder-consumer` et les autres. Si une skill n'apparaît pas : vérifie que `SKILL.md` est bien à la racine de chaque dossier copié.

## Désinstallation

```bash
rm -rf ~/.hermes/skills/founder-*
```

Les outputs (`founder/`) sont dans tes projets, pas dans les skills : tu peux retirer le pack sans rien perdre.
